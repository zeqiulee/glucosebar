# 安装与首次连接

## 先确认适用

真实账号目前只验证了国内版「硅基动感」GS1 + iPhone。Mac 需要 macOS 14+。iPhone 负责与传感器通信和上传，Mac 读取云端，可能比手机晚。没有蓝牙直连、Apple 健康同步或独立告警。

你需要自己账号的有效登录凭证，不要把密码或 token 发给维护者。

## 获取应用

尚未完成 Developer ID 签名和 Apple 公证。普通用户请等待明确标为已签名、公证且通过独立 Mac 验证的版本；愿意早期技术测试的用户，可从源码构建，或评估 Release 中清楚标记的未公证构建。

在 [Releases](https://github.com/zeqiulee/glucosebar/releases) 查看支持范围、架构、公证状态和已知问题。`arm64` 对应 Apple Silicon，`x86_64` 对应 Intel，`universal` 包含两者。仅下载匹配构建；交叉编译成功不等于目标硬件已验证。

如附有 `SHA256SUMS.txt`，可用 `shasum -a 256 下载文件.zip` 对比。校验和核对文件一致性，不保证业务安全。遇到 macOS 安全提醒，先核查版本的签名状态，不需要关闭系统安全保护。

## 先看演示

打开后进入设置，点击「预览界面演示」，无需登录。展开菜单栏查看曲线、切换时间范围和显示模式。曲线演示有「演」标记，数字演示有「演示」标记。

退出演示后才恢复本人记录读取。演示图不是实际测量结果。

## 获取并输入本人凭证

当前需要在自己的 iPhone 使用 HTTPS 调试工具；比普通登录复杂，是早期版本限制。不熟悉证书配置时，可先只看演示，等待更简单的授权方式。

1. iPhone 登录「硅基动感」，确认最新读数与测量时间正常。
2. 选择支持 HTTPS 解密的调试工具，按其官方向导配置；无需购买指定工具。[HTTP Catcher 官方说明](https://docs.httpcatcher.com/quickstart) 可供参考。
3. 若工具要求根证书，按 [Apple 手动信任证书说明](https://support.apple.com/zh-cn/102390) 配置，只在本次调试期间启用，结束后移除。
4. 开始抓取，筛选 `api.sisensing.com`，打开硅基动感刷新记录。
5. 在返回 200 的相关请求头里查看 `Authorization`，复制 `Bearer` 后的值。这是访问凭证，不要发送到聊天、Issue 或截图里。
6. 直接粘入 Mac App 的安全输入框，点「保存并验证连接」。如有钥匙串提示，只在 macOS 系统窗口完成。
7. 停止抓取和调试工具的 VPN，移除它安装的证书描述文件，并清除含凭证的抓包记录。

失效后需要重新获取；异机登录、重新安装或服务端变更都可能影响有效性。应用无法替厂商刷新或撤销 token。

## 连接后核对

对照手机的**测量时间、数值、单位、趋势**，确认是本人当前传感器。多个传感器可在面板选择，默认跟随当前传感器。不要仅凭图线相似就认为正确。

显示「旧」、曲线变淡或提示过期/异常时，先看测量时间和手机上传。每分钟检查云端，失败会退避；频繁刷新不会让传感器更快产生数据。

「健康比例」实际是固定参考区间 3.9–6.9 mmol/L 内估算时长，除以所选完整窗口。缺口不计区间内，悬停可查看覆盖率；不是诊断或通用健康评分。

## 常见问题

**没有 Dock 图标？** 应用在顶部菜单栏运行，重新打开 App 可进入设置。

**没有读数？** 确认已退出演示，检查凭证状态、iPhone 上传和传感器运行状态；凭证失效时更新。

**Mac 与手机不同？** 先比较测量时间，云端上传、网络与后台限制可能造成延迟。继续使用原 App 告警。

**更换凭证后历史消失？** 不匹配的旧缓存不会加载，云端成功后会重建本机缓存。

**清除失败？** 不要把失败当作已全部删除。检查本机目录权限；报告版本和静态错误文字即可，不上传缓存文件。

## 退出和卸载

点击菜单栏图标，选面板右下角「退出」。关闭普通窗口只收起窗口，不等于退出菜单栏进程。

卸载前关闭「登录 Mac 后启动」，点击「清除凭证与本机缓存」，确认没有失败提示，再退出并将 App 移到废纸篓。只删除 App 不会自动删除钥匙串和健康缓存。备份、快照或自行导出文件另行管理。
