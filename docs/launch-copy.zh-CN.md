## 常见问题答复素材

### 谁现在适合试用？

国内版硅基动感 GS1、iPhone 原 App 正常上传、Mac 使用 macOS 14 或更新系统，并愿意接受测试版限制的用户。其他型号、海外版和其他云端服务尚不能因为名称相似就认为兼容。

### 是硅基官方的软件吗？

不是。GlucoseBar 是独立个人项目，使用社区研究的云端接口；没有厂商授权或合作背书的声明。

### 是通过蓝牙直接读取传感器吗？能读 Apple 健康吗？

当前都不是。iPhone 原 App 上传数据后，Mac 使用你的本人凭证读取云端记录。手机上传、网络和接口状态都会影响读数的及时性。

### 一分钟刷新一次，就是实时的吗？

不是。刷新只是在检查云端，云端尚未收到的测量无法显示。界面会显示测量时间及旧数据状态；不要用菜单栏来替代原 App 告警。

### 下载 ZIP 为什么没有 App？

GitHub 首页 `Code → Download ZIP` 下载的是源码。应用安装包如果已经发布，应在对应 Release 的 Assets 中；按该版本说明选择芯片和系统匹配的包。没有公开的应用资产时，不要把源码链接称作安装包。

### 为什么连接步骤需要登录凭证？

当前没有厂商提供给本项目的公开登录接入方式，因此需用户自行从本人 App 获取云端凭证。凭证相当于账号访问凭据，只输入本机 GlucoseBar，不发给维护者。按教程完成后应停止抓包并移除临时证书。

### 数据会发送给维护者吗？

当前应用直接读取硅基云端，没有维护者数据服务器或分析埋点；登录凭证保存在本机钥匙串，记录缓存在本机。提交 GitHub Issue 则是主动对外发布，请不要附上凭证、请求头、抓包文件、真实健康数据或账号信息。

### 图中的比例能判断我是否健康吗？

不能。该比例只是固定自定义参考区间内的估算时长占所选完整时间的比例，缺失时长也保留在分母里。它不是通用健康评分；解释算法时同时说明数据覆盖情况，不把该区间宣传为所有人的健康标准。

### 下载后 macOS 阻止打开怎么办？

先核对该 Release 是否明确说明已完成 Developer ID 签名、公证，以及是否匹配你的系统和芯片。未公证技术预览不承诺普通用户直接安装；不要关闭系统安全保护来完成测试。可等待签名公证版本，或由具备开发经验的用户按源码构建说明自行构建。

### 怎么关闭、停用或卸载？

在展开面板点击“退出”。停用前可关闭“登录 Mac 后启动”；如需删除本机连接，在设置中清除凭证与缓存并确认结果，再退出和移除 App。若清除提示失败，不要认为数据已删除，先按文档排查或反馈不含个人信息的错误类别。
